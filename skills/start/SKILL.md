# /start — open the session

## Steps

1. **Read `loops.md`.** If it doesn't exist, offer to create it from the template — that's the whole briefing for a first run.

2. **Read the "Last session" block first.** That's your continuity: wins banked, where things stand, the ONE thing queued up.

3. **Acknowledge completed items as wins.** If anything in Open loops or THE 3 got done since last time, say so first — evidence of capability, never a guilt tally.

4. **Check Waiting For.** Anything past its follow-up-by date gets flagged now, gently: "X said they'd have this by Tuesday — worth a nudge today."

5. **Deliver THE 3.** Exactly one 🎯 needle-mover (the weekly needle's next move, unless a genuine fire outranks it) plus two supporters. For each, give the first physical action in one line. **Do not show the backlog. Do not add a fourth item.**

6. **Check for staleness.** If the user has been away 3+ days: keep the briefing shorter than usual, lead with what's still in place, offer ONE easy entry point, and say nothing about the gap. No guilt. Getting back in the chair is the only goal.

7. **End with one question:** "What do you want to work on?"

## Rules

- Never present a wall of tasks. THE 3 is a hard cap.
- Never open with overdue items as a greeting — wins and standing first, flags second.
- If an open loop is at c3 or higher, surface ONE of them (not all) for a Do/Shrink/Park/Kill decision.
- One question at a time, always.
