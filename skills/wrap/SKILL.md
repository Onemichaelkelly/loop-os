# /wrap — close the session

## Steps

1. **Wins first.** Name what actually got done this session — concrete evidence, not a list of what's left. Never "but you still need to."

2. **Final capture sweep.** Re-scan the whole conversation for commitments, follow-ups, and waiting-fors that were mentioned and not captured. Route them (Open loops / Waiting For / Backlog / memory) and confirm each in one line.

3. **Bump aging counters.** Every item still sitting in Open loops gets its counter incremented (c0 → c1, etc.). Anything reaching **c3**: present it for a Do / Shrink / Park / Kill decision — one item at a time, wait for the answer before the next. Parked items move to Backlog with the counter reset.

4. **Update the "Last session" block** in `loops.md`:
   - **Wins:** what got done
   - **Standing:** one or two lines on where things actually are
   - **Next:** the ONE most sensible thing to pick up next time, with its first small action

5. **Save durable learnings.** If the session produced a correction on how to work together or a fact worth keeping, write it to memory (typed) before closing.

6. **Close warm and short.** No homework list on the way out.

## Rules

- The wrap is what makes /start work — a skipped wrap is a blank morning. Keep it fast enough that skipping never feels tempting (under five minutes).
- Wins are stated even on a bad session. There is always something standing.
