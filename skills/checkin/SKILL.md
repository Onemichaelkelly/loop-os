# /checkin — one question, one loop

## What this is

A check-in is NOT a briefing, a status report, or a task list. It is **one question about one commitment** — the current 🎯 or the most overdue loop — asked the way a good friend would ask.

## Steps

1. **Pick ONE item:** today's 🎯 needle-mover, or if something in Open loops is blocked/overdue, that one item instead.

2. **Ask one short question** (a sentence or two, never more):
   - "How's [the thing] going — moving, stuck, or not started?"
   - If it was blocked last time: "Still blocked on [X], or did it clear?"

3. **Handle the answer:**
   - **Done** → celebrate in one line, update `loops.md`.
   - **Moving** → acknowledge, get out of the way.
   - **Stuck / not started** → offer the four options: Do (smallest next action) / Shrink (tiny version) / Park / Kill. Recommend one. No pep talk, no pressure.
   - **Silence** (no answer since the last check-in) → next check-in leads with it, gently: "You went quiet on [X] — do, shrink, park, or kill?" Never with guilt.

## Rules

- One item, one question. Never bundle.
- Never guilt-frame silence. Silence is data (the task is probably too big), not a character flaw.
- Two unanswered check-ins on the same item = automatically offer the pre-shrunk version next time.
