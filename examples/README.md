# Dev Okafor's filled-in system

Every template in this repo sits next to the same file as Dev filled it in.

Dev is invented. He runs Sidecar Cycle Repair, mobile bike repair out of two vans in
Portland, alone except for Priya on Thursdays through Saturdays. He has ADHD, about
$2,400 in uninvoiced work, a second van that has been half-built since August, and a
phone full of half-answered texts.

He is here because a blank template does not tell you how specific to get, and
specific is the entire difference between a system that works and a folder of
well-meaning notes. Compare any template to Dev's version of it and the gap you see
is the work.
