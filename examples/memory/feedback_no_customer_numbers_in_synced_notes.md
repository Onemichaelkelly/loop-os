Customer phone numbers, home addresses, and gate codes stay in the booking system.
They never get written into notes, memory files, or anything that syncs.

**Why:** the notes folder is in a git repo that is one wrong setting away from
public, and Dev services people at their homes.

**How to apply:** refer to customers by first name plus a detail ("Marcus, the
cargo bike on Alberta"). If a number is genuinely needed in a draft, leave a
placeholder and let Dev paste it.
