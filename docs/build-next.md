# What was deliberately left out

Seven skills ship. That is a cap, not a budget that happened to run out. Past
seven, the install faces the same wall this system exists to prevent, and nobody
reads past the third command they never used.

Here is what got cut and why. None of it is hard to add once the core holds.

## Cut because it is second-layer

**Lane conductors.** One skill per area of your work (a client, a brand, a
product), which loads that area's rules and routes to sub-skills. This is the
pattern that makes a system scale past one person's head, and it is genuinely
worth building. It is also meaningless until you have enough rules to need
routing. Build it around month three, not week one.

**A knowledge-graph builder.** Turning notes, code, or documents into a linked
graph you can query. Powerful, and completely separate from the promise of this
repo.

**A skill that writes skills.** Useful once you are writing your fifth one. Before
that, writing them by hand is how you learn what a good description looks like.

## Cut because something here already does it

**A separate mini-wrap.** Folded into `/wrap` as `--mini`. Same job, one command
to learn instead of two.

**A dedicated open-loops scanner.** `loops.md` and `/start` already carry this,
with aging counters doing the work a scanner would. A second one produces two lists
that disagree.

**A memory consolidator.** The periodic audit in `docs/memory-model.md` covers it:
read the whole folder back every so often and fix stale facts, contradictions, and
index lines pointing at nothing. Worth turning into an `/audit` skill once your
memory folder passes about fifty files.

## Cut because it is somebody's specific job

Content pipelines, SEO tooling, review responders, publishing workflows. These are
excellent and they are *someone's*. Yours will not look like theirs. Build them
once the core is holding and you know what you actually repeat.

---

The order that works: run this for two weeks. Notice which correction you keep
making. That correction tells you what to build next, and it will not be the thing
you would have guessed today.
