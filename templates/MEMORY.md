# Memory Index

One line per memory file, written as `stem — hook`, under 150 characters. No markdown
links: the stem is what gets opened, and the hook is what decides whether to open it.

This index loads every session. Individual files are pulled only when relevant, which
is what keeps it cheap.

user_profile — who I am, what I do, what shuts me down, what gets me moving
feedback_communication — corrections given on how to work with me: one question at a time, no walls of text
